v5.60 관련 확인
---------------
GitHub에는 v5.60 설치/업데이트 커밋과 배포 실행 파일은 남아 있으나,
그 실행 파일을 컴파일한 본체 Go 프로젝트 전체는 남아 있지 않다고 저장소의
README 및 app/README에 명시되어 있습니다. 따라서 이 패키지를 v5.60의
정확한 1:1 재현 소스라고 표시하지 않습니다.

go.sum 관련
------------
회수된 루트 프로젝트와 GitHub app 프로젝트 모두 표준 라이브러리만 사용하는
go.mod이며 원본에 go.sum이 존재하지 않습니다. 원본 보존을 위해 빈 go.sum을
새로 만들지 않았습니다.

검증 제한
---------
현재 작업 환경에는 Go 컴파일러가 설치되어 있지 않아 재빌드 검증은 수행하지
못했습니다. 원본의 build_windows.bat와 Windows 리소스 파일은 포함했습니다.
