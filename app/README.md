# JTSN 메인 프로그램 복구 소스

이 폴더는 이전 ChatGPT 대화에 첨부된 `JTSN_v5.1_Source.zip`에서 회수한
마지막 빌드 가능 메인 프로그램 원본입니다.

## 확인 결과

- 기준 버전: v5.1
- 언어: Go
- 모듈: `jtsn`
- Windows 빌드 확인: 성공
- 현재 공개 버전: v5.60

현재 v5.60 배포 실행 파일의 소스 전체가 공개 대화나 GitHub에 남아 있지
않으므로, 이 소스는 복구 기준점으로 사용합니다. v5.1 이후 기능을 이 코드에
되살린 뒤 충분히 검증하기 전까지 v5.60 배포 실행 파일을 교체하지 않습니다.

## 복원된 기능

- 메인 화면 기능 검색: 이름과 관련 키워드를 입력하면 도구 카드가 즉시 필터링됩니다.
- 탐색기 우클릭 연동: 파일·폴더에서 인쇄, PDF, 파일명 변경, 이미지 변환,
  중복파일 찾기, 폴더 일괄 생성 도구를 바로 열 수 있으며 앱에서 등록·해제합니다.
- 중복 실행 방지: 메인 프로그램을 다시 실행하면 기존 창을 앞으로 가져옵니다.
- 호출 단축키 기반: `Ctrl+Shift+J`로 기존 메인 창을 복원합니다.

## 빌드

Windows에서 Go 1.23 이상을 설치한 뒤 이 폴더에서 실행합니다.

```powershell
go test ./...
go build -o JTSN.exe .
```
