# JTSN v5.55 설치형 자동 업데이트 프로그램

JTSN v5.50 본체를 포함하고 GitHub Releases에서 최신 버전을 확인하는 부트스트랩 실행기입니다.

## v5.55

- 손상된 축약 본체 대신 실제 Windows x64 JTSN v5.50 본체 포함
- 실행 파일의 버전 문자열을 바이너리 수준에서 치환하던 처리 제거
- 설치 시점의 `%LOCALAPPDATA%`를 사용해 바탕화면 바로가기 대상 생성
- 정상 본체를 Git LFS로 추적해 재현 가능한 설치 빌드 보장

## v5.54

- EXE 하나만 내려받아 설치하는 단일 설치 파일 방식
- 설치 위치, 설치 진행률, 완료 상태를 표시하는 설치 마법사 추가
- 설치 완료 후 `JTSN` 바탕화면 바로가기 자동 생성
- 설치 완료 후 프로그램 자동 실행
- 다운로드한 설치 파일 이외의 사용자용 보조 파일 불필요
- GitHub 릴리스 파일 자체의 SHA-256 해시를 이용하는 업데이트 검증 지원

## v5.53

- 사용자 전용 프로그램 폴더에 본체 설치
- 바탕화면에 JTSN 바로가기 자동 생성
- Windows 앱 제거 목록 등록
- 업데이트 백업 파일을 설치 폴더 내부에서 처리하고 성공 후 자동 삭제
- 기존 바탕화면 실행 파일과 `.bak` 파일 자동 정리
- 프로그램 표시 버전 및 최초 실행 패치노트 버전 동기화

- 최신 릴리스 확인
- EXE 및 SHA-256 다운로드
- 체크섬 검증
- 실행 파일 자동 교체 및 재실행
- 실패 시 기존 실행 파일 복구

최초 내려받은 EXE를 실행하면 사용자 전용 프로그램 폴더에 설치되고,
이후에는 바탕화면의 `JTSN` 바로가기로 실행합니다.
